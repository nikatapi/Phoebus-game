# Feebus Carderinius

A 2D action platformer for Android about a goldfinch who collects video game cartridges and Bobblebird figures, powered by the zodiac.

**Run it:** install [Godot 4.3](https://godotengine.org/download), open `project.godot`, press F5. Keyboard: arrows/A-D move, Space jump (hold to glide), C power, V swap power. Mouse clicks emulate touch for the on-screen buttons.
